Scaling

  • Chunk relay latency is how late each streamed chunk reaches the client compared with when the upstream sent it, measured per chunk with a timestamp inside the payload. It is the number a developer feels as a stuttering stream, and the first to rise when an event loop is blocked.
  • TTFB overhead is time to first byte minus the upstream's fixed 300ms. It includes reading a 64 KB request body, identity lookup and routing.
  • A stage holds when it meets every SLO. "Developers within SLO" is the last stage before the first one that fails. The grey dashed line is the bench talking to the fake upstream with no Fest at all, which is the measurement floor.
  • Every process shares one machine with the load generators and the fake upstream, so absolute numbers depend on this hardware. Compare runs from the same machine.
